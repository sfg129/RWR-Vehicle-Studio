# RWR Vehicle Studio 0.6.1

- 新增专用的 `MAP 对象` 工作区，可直接查看和编辑 `objects.svg` 中的固定载具、部署物及阵营 tag 刷新点。
- 原版与模组 `maps` 根目录、Vehicle 目录和 Faction 目录可分别选择并持久保存；保存时自动创建目标地图子目录，且不生成地图 `.bak` 文件。
- 支持地图背景、基地范围和图层显示，提供搜索、位置与方向拖动、key/tag 编辑、复制、删除、撤销及资源候选诊断。
- 修正 RWR 对地图 SVG 的特殊兼容要求：替换节点保留原几何数据，几何编辑使用矩阵变换，新节点使用 `spawn_rwrmap_N` ID，并自动迁移旧版 Studio 产物。
- 优化大型地图的拖动、缩放与标签绘制性能。
- ICON 渲染新增“主体/完整轮廓”构图基准；默认按车体主体定标，避免长炮管和天线使图标主体过小或偏心，同时仍完整导出所有模型。
- 默认图标留白缩小，并更新图集嵌入流程，使 Studio 已完成构图的透明 PNG 可直接按画布嵌入槽位。

正式发布资产覆盖 Windows、macOS 与 Linux；Windows 同时提供安装程序和便携版 EXE。
