# 审计问题定义

本文档集中定义 PR/提交信息中引用的审计编号，方便读者不依赖前序审计材料即可理解每个编号的含义。

- **R3-xxx**：第三轮增量审计（`RWR-Vehicle-Studio-Third-Audit-Delta-254629e.md`）新增/复核的问题编号。

- 状态栏以当前 main 为准；具体审计基线见最近 R5 条目。
